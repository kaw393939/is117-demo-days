# Skills to build next

Use job descriptions as evidence about the work, not a checklist that one course must teach in full. This roadmap is a teaching synthesis from the linked [internship examples](/career/internships).

| Area | Practice in IS117 | Develop further |
| --- | --- | --- |
| Business discovery | Audience, competition, needs, and workflow | Interview users, establish baselines, measure adoption/results |
| Communication | Explain decisions and demonstrate a useful task | Customer workshops, technical trade-offs, training and handoffs |
| Programming | HTML/CSS/JavaScript and your project's application logic | Strong Python/TypeScript, data structures, debugging unfamiliar code |
| Data | SQLite-backed simulated storefront | SQL, data modeling, migrations, data quality and pipelines |
| Integrations | Understand inputs, outputs, and simple API use when applicable | REST APIs, authentication, retries, webhooks, external systems |
| AI | Use coding tools with verification; optional bounded product feature | Retrieval, tool use, evaluation sets, cost/latency, human review |
| Collaboration | Balanced tasks, reviews, integration | Larger codebases, pull requests, iterative delivery |
| Deployment and QA | Publish, exercise core paths, document limits | Automated tests, cloud operations, logs, monitoring, reliability |

## A useful next project

After IS117, choose one working project and deepen it. Add a real server/API, improve data persistence, automate an important check, get feedback from a real user, and document what changed. Depth and evidence are more useful than a list of tools you cannot explain.

## Present yourself accurately

Write résumé bullets using an action, implemented scope, and evidence. Example: “Built a simulated storefront with size selection, cart totals, and SQLite order storage; verified the checkout journey and documented known limitations.” Use that statement only if you actually completed those things.

Do not claim measured time savings or conversion improvements without data. Your desired career direction can be ambitious while your description of current skills remains accurate.

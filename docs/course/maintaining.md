# Maintaining this guide

## Editing and publishing

Edit Markdown in `docs/`, then run `npm ci`, `npm run check`, and `npm run docs:build`. GitHub Actions publishes the existing Pages site from main.

## Course changes

Canvas owns class and demo dates and times, booking, submission settings, weights, scores and feedback. Edit those only in Canvas. The course book explains the work and links to Canvas. Keep the existing demo section URLs as pointers, not mirrors. Do not collect private circumstances, calendars, or meeting links in GitHub issues.

## Keep career references useful

Retain the employer URL, research date, location, eligibility, deadline wording, and evidence status. Mark closed or unverified roles as examples. These source dates are not course deadlines.

## Milestone publication status

Use the matching Canvas section to verify actual assignment and module settings. Do not use a prior Student View snapshot as a current check.

## Grading reference {#review-categories-and-final-assessment-setup}

Use Canvas Grades for current settings. The public rubric describes existing evidence criteria and does not change assessment policy.

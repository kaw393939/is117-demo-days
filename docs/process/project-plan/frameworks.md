# Choose a framework and libraries

Watch the [React documentary](https://www.youtube.com/watch?v=8pDqJVdNa44). Look for the idea of building a page from pieces. A **component** is one piece, such as an order summary. **State** is information that can change, such as the quantity a visitor selects. Think about what the page should show when that value changes. [Thinking in React](https://react.dev/learn/thinking-in-react)

| Option to research | What to ask |
| --- | --- |
| **Next.js** | Can my features run in its static export? [Next.js static export](https://nextjs.org/docs/app/guides/static-exports) |
| **SvelteKit** | Can I publish the pages I need with its static adapter? [SvelteKit static adapter](https://svelte.dev/docs/kit/adapter-static) |
| **A library** | What specific job would it do? Check what your framework or browser already provides before adding a dependency. |

Ask AI to compare two frameworks for your main task, hosting, and setup. Verify one claim in the official docs. In your plan, name your choice, one tradeoff, and any libraries you actually expect to use.

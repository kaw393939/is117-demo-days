# Hosting, browser storage, and demo checkout

**Hosting** makes your built site available at a link. Publish the T-shirt prototype and portfolio on GitHub Pages. Try publishing early and check that your links and images work from the public URL. [About GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages)

**Browser storage** lets the site remember demo data in the same browser. For the T-shirt demo, plan to save a fake order reference, selected size, quantity, and total. Place a fake order, reload the page, and check that the reference and total are still there. Say how you can clear the demo history. [Try the course example](/examples/submissions/run-examples#run-the-save-and-reload-check) · [Read about localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)

**Optional research:** Shopify is a commerce platform. Stripe handles payments. Vercel is another hosting option. Compare what they could add to a future version. Use pretend orders for class and keep real payment and customer details out of the demo. [GitHub Pages usage limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

# Mobile, accessibility, and privacy

- **Mobile:** Try your main task on a phone. Check that text is readable, controls are easy to tap, and nothing important runs off the screen.
- **Accessibility:** Try it with Tab, Shift+Tab, and Enter. The focused control should be visible. Check form labels, color contrast, and useful image descriptions. Try a mistake, such as leaving size blank, and check that you can understand and fix it. [W3C Easy Checks](https://www.w3.org/WAI/test-evaluate/preliminary/)
- **Privacy and legal:** List what your demo stores and how to clear it. Use fake order data. Check the license or permission for images and fonts. For a real launch, research what personal data you need, how you would explain its use, and when you would delete it. [EU data-protection principles](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/principles-gdpr_en)

In your plan, name the task you’ll test and what passing looks like. Add the result when you run the check in Build.

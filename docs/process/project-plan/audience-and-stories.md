# Audience, sketches, and user stories

Start with one person and one task. A shopper may need to check fit before adding a shirt. An internship reviewer may need to see what you built before opening your résumé.

1. Pick one finding from your research that affects the design.
2. Sketch two ways to support the same task. For a portfolio, try showing projects first in one version and a short introduction first in the other. The same content can serve both.
3. Write a **user story** and a **check**. The check says what you expect to happen when someone tries the task.

**Example:** “As a shopper, I want to see the total before I place a demo order so I can check the price.” Select two $25 shirts. The order summary should show $50.

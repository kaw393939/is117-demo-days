# Try the three-project source

These are fictional class projects you can open in a browser. [Download the source and project records](/student-trial-source.zip) or try [Day One Cotton](/student-trial/shirt/a.html), [Campus Cycle](/student-trial/group/a.html), and [Nina’s portfolio](/student-trial/portfolio/a.html).

Keep `prototype-storage.js` next to the `student-trial` folder when publishing the files to GitHub Pages. The prototypes use HTML, CSS, and JavaScript.

## Check what the site remembers

1. In the shirt demo, save a fake order. In the group demo, save a fake repair request.
2. Reload each page. Look for the same reference in that page’s history.
3. Open the other version in the same browser. Both versions share the demo’s saved history.

A repair request stays pending. No appointment is booked, no message is sent, and the demo email is never saved. The portfolio shows projects and links.

# Shared style guide — Nina rehearsal
Wordmarks: Day One Cotton, Campus Cycle and Nina Shah are text logos. No borrowed logos. SVG shirt/bicycle illustrations were authored with code and are labeled illustrative.

Type: system sans-serif; clear sentence-case headings. Shirt/group headings use a large product lead; portfolio headline was reduced after visual inspection so evidence appears sooner.

Colors: ink #17312f; paper #f6f4ee; sage #e2e7db; white cards; focus outline #a55324. A uses adjacent context/action; B uses a stacked sequence and cooler background #e7edf1. Rounded A versus square B cards reinforce a friendly-versus-editorial comparison without changing workflow.

Voice: specific, calm, honest beginner. Shirt Everyperson; group Caregiver; portfolio approachable helper. Modernist functional hierarchy supports the chosen audience; expressive postmodern storytelling was considered for the alternate audience, not treated as a synonym for “bad design.”

Persuasion applications are hypotheses: useful fit/next-step guidance supports reciprocity; repeating choices supports commitment/consistency. No fabricated urgency, reviews, authority or efficacy claims.

Logo, color, voice, audience and workflow decisions live with the project record; this is a reference, not an added Canvas submission.
